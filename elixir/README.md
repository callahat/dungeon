# dungeon

Various dungeon generation algorithms.

## Usage

Make sure elixir is installed.

```elixir
asdf install
```

Run mix to bring up the REPL from the `generators` directory

```elixir
iex -S mix
```

Run the various generators from the REPL, ie Dungeon2

```elixir
Dungeon2.generate
```

See the various generator readmes for more information on the different algorithms

[Connected Rooms](./generators/lib/connected_rooms/README.md)
